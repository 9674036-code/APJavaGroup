# Branching Story

## Project Purpose
Create an interactive story where users make choices that lead to different scenes and endings.

## Scenario
The program presents different situations and allows users to choose what happens next. Each choice leads to another scene or an ending.

## Node Structure
Each node represents a scene in the story. Nodes connect to other nodes based on the user's choices. Some nodes are final endings.

## Recursive Method
The recursive method is called `choice()`. It takes the current location as a parameter, checks the user's decision, and recursively moves to the next location. Recursion stops when the user reaches an ending.

## Testing
We will test different choices to make sure they lead to the correct scenes and endings.

## Running the Program
Run the main Java file and follow the instructions to make choices and progress through the story.
